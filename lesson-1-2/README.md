# レッスン 1-2: WranglerでWorkerを作ってworkers.devに公開しよう

Cloudflare開発コースのレッスン 1-2 を終えた時点の完成コードです。自分のコードと見比べるときに使ってください。

## 動かし方

```bash
npm install
npm run dev
```

- `wrangler.jsonc` の `xxxxxxxx` などの値は、自分で作ったリソースの ID に置き換えてください
- 秘密の値（`ADMIN_TOKEN` など）は `.dev.vars` に書きます。このリポジトリには含めていません
- 手順と説明は、Code Lesson の教材本文を参照してください
